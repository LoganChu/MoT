Measured, not simulated

What actually trains in a Mixture‑of‑Transformers

MoT gives every modality its own transformer weights but lets one attention operation see the whole sequence. That raises an obvious worry: if each expert only ever touches its own tokens, what stops the modality with more data from running away with the training? This page answers that by instrumenting a small MoT and watching — per layer, per expert, per step.

The setup

A task that cannot be solved one modality at a time

Each scene is a 3×3 board holding one to three coloured shapes, written two ways: a caption and a row of patch codes (a stand‑in for the VQ tokens a real image tokenizer emits). The two views are in bijection, so in a caption → image document the image tokens are predictable only by attending back to the caption, and vice versa. That is what makes cross‑modal attention something we can measure rather than assume: switch it off, and the loss on exactly those tokens has to get worse.

What is split, what is shared

Following Liang et al., arXiv:2411.04996

Per modality: the feed‑forward network, the Q/K/V/O projections, the QK‑norms and every layer norm. Shared: the embedding, the output head, and — the whole point — a single causal attention over the full interleaved stream. Routing is deterministic from the token's modality; there is no learned router.

Why both experts start identical

A measurement choice, not standard practice

Both experts are initialised to exactly the same weights. Divergence between them is therefore pinned to zero at step 0, so anything we see later is caused by training rather than by initialisation noise. In ordinary practice you would initialise them independently.

The control that makes this trustworthy

Blocking cross‑modal attention

If the off‑diagonal were an artefact of the measurement, it would survive when cross‑modal attention is masked out. It does not: in the blocked_attention run it is identically zero, to the last bit, at every layer and every step — and the diagonal stays healthy. This is asserted in the test suite, not just observed.

The mechanism — cross‑run comparison

Adam hides the imbalance; SGD shows it

A starved expert accumulates gradient from fewer tokens, and the first panel shows exactly that — the image expert's gradient norm sits well below the text expert's all through training. But Adam divides by a running second moment, so the size of the step it actually takes barely changes. Under plain SGD the same imbalance lands straight in the step size. Both panels are the same 85/15 token mixture; only the optimiser differs.

Reading this honestly

What transfers and what does not

Magnitudes do not transfer. This is a small model on synthetic data with a nine‑token image. Do not carry a specific percentage here to a 7B run.

The mechanisms are what transfer. That gradient exposure scales with token count while Adam's step size does not; that global attention creates a gradient path into every expert regardless of its own token share; that specialisation is layer‑dependent. Those follow from the architecture and the optimiser, not from this task.

Identical initialisation is not standard. It is used here so that divergence starts at exactly zero and is attributable to training.

One task, one seed. Every run uses seed 0 and the same synthetic corpus, so run-to-run variance is not characterised here. The directional results are large and consistent with the mechanism, but the precise ratios should be read as this run's numbers rather than as estimates with error bars.

Every number on this page was measured by scripts/run_all.py and bundled by viz/build.py; nothing is illustrative. Architecture follows Mixture‑of‑Transformers (Liang et al., TMLR 2025) and its reference implementation.
